# Security

Report vulnerabilities privately through this repository’s GitHub **Security →
Report a vulnerability** feature. Do not put credentials, customer content or
signed reference URLs in public issues. Include the SDK revision, affected
operation, reproduction using synthetic data, and a request ID when available.

Keep Cortex keys server-side. Your application remains responsible for user
authentication, ownership, quotas and durable storage. The Supabase schema is an
optional example; adapt existing schemas through CortexStore.
